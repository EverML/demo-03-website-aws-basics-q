Static Website Hosting on AWS

Learn how to host a static website using Amazon S3 and CloudFront for global distribution.

Overview

Hosting a static website on AWS is one of the most cost-effective and scalable solutions for delivering web content. In this tutorial, we'll walk through the process of setting up a static website using Amazon S3 and CloudFront.

What is a static website? A static website consists of HTML, CSS, JavaScript, images, and other files that are delivered to users exactly as stored. Unlike dynamic websites, static sites don't require server-side processing for each request.

Step-by-Step Guide

1

Create an S3 Bucket

First, we need to create an S3 bucket to store our website files. The bucket name must be globally unique.

S3 Management Console
Must be globally unique

Alternatively, you can use the AWS CLI:

aws s3api create-bucket --bucket my-static-website-bucket --region us-east-1
2

Configure S3 for Static Website Hosting

Next, we need to configure the bucket for static website hosting and set the proper permissions.

Enable Static Website Hosting

S3 Bucket Properties

1. Go to your bucket properties

2. Scroll down to "Static website hosting"

3. Click "Edit"

Set Bucket Policy

To make your website publicly accessible, you need to add a bucket policy:

{
    "Version": "2012-10-17",
    "Statement": [
        {
            "Sid": "PublicReadGetObject",
            "Effect": "Allow",
            "Principal": "*",
            "Action": "s3:GetObject",
            "Resource": "arn:aws:s3:::my-static-website-bucket/*"
        }
    ]
}
Security Note: This policy makes all objects in your bucket publicly readable. For production websites, consider using CloudFront with Origin Access Identity for better security.
3

Upload Website Files

Now it's time to upload your website files to the S3 bucket.

S3 Bucket Objects

Drag and drop files here or click the Upload button

Using AWS CLI to upload a website directory:

aws s3 sync ./my-website-folder s3://my-static-website-bucket/ --acl public-read

At minimum, you should upload:

  • index.html (main page)
  • error.html (error page)
  • CSS, JavaScript, and image files
4

Access Your Website

After uploading your files, you can access your website using the S3 website endpoint.

http://my-static-website-bucket.s3-website-us-east-1.amazonaws.com

The endpoint format varies by region. You can find your specific endpoint in the "Static website hosting" section of your bucket properties.

Note: At this point, your website is accessible over HTTP, not HTTPS. To enable HTTPS, we need to set up CloudFront in the next step.
5

Set Up CloudFront Distribution (Optional but Recommended)

CloudFront is AWS's Content Delivery Network (CDN) that speeds up distribution of your static content by caching it at edge locations around the world. It also provides HTTPS support.

Create a CloudFront Distribution

CloudFront Create Distribution

After creating the distribution, CloudFront will provide you with a domain name like:

d1234abcdef.cloudfront.net

You can now access your website securely via HTTPS using this domain.

6

Set Up Custom Domain (Optional)

If you have a custom domain, you can use Amazon Route 53 to point it to your CloudFront distribution.

Steps:

  1. Register a domain with Route 53 or transfer an existing domain
  2. Create a hosted zone for your domain
  3. Create an A record that points to your CloudFront distribution
  4. Request an SSL certificate using AWS Certificate Manager
  5. Update your CloudFront distribution to use the custom domain and certificate
Note: Setting up a custom domain is beyond the scope of this basic tutorial, but AWS provides detailed documentation on this process.

Best Practices

  • Use CloudFront with Origin Access Identity to secure your S3 bucket
  • Enable versioning on your S3 bucket to recover from accidental deletions
  • Set up a CI/CD pipeline for automated deployments
  • Optimize images and assets to reduce load times and costs
  • Use a custom error page to handle 404 errors gracefully
  • Implement caching strategies in CloudFront to improve performance

Conclusion

You've now learned how to host a static website on AWS using S3 and CloudFront. This approach provides a scalable, reliable, and cost-effective solution for hosting static websites.
