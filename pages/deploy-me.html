Deploy This Website to AWS

Experience the deployment process firsthand by deploying this website to your own AWS account.

Deploy to Your AWS Account

This page allows you to deploy this exact website to your AWS account using S3 and CloudFront, just like you learned in the tutorial. The deployment process will:

  • Create an S3 bucket with a unique name
  • Configure it for static website hosting
  • Upload all website files
  • Create a CloudFront distribution for global delivery
  • Provide you with the URL to access your deployed site
Note: This will use the "ever" AWS profile configured on your system. Make sure this profile has the necessary permissions to create S3 buckets and CloudFront distributions.

Manage Deployment

Use the buttons below to deploy or destroy this website on your AWS account:

Deployment status will appear here...

The deployment process may take a few minutes. CloudFront distribution creation can take up to 15 minutes to fully propagate.

The destroy process will remove all AWS resources created for this website.

How It Works

When you click the "Deploy to AWS" button, the following happens:

  1. A bash script is executed on your local machine
  2. The script uses the AWS CLI with your "ever" profile to create resources
  3. It creates an S3 bucket with a unique name based on the current timestamp
  4. The bucket is configured for static website hosting with proper permissions
  5. All website files are uploaded to the bucket
  6. A CloudFront distribution is created pointing to the S3 bucket
  7. The deployment details are returned and displayed on this page

Cleaning Up Resources

When you click the "Destroy Site" button, the following happens:

  1. A bash script is executed on your local machine
  2. The script uses the AWS CLI with your "ever" profile to remove resources
  3. It disables the CloudFront distribution
  4. It waits for the distribution to be disabled
  5. It deletes the CloudFront distribution
  6. It empties the S3 bucket (deletes all files)
  7. It deletes the S3 bucket
  8. It removes the local deployment information file
Important: This will create actual AWS resources in your account that may incur charges. While the costs for this demo should be minimal, remember to clean up resources when you're done experimenting by clicking the "Destroy Site" button.
